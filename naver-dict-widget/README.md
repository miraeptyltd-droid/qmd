# 영어사전 위젯 (Windows)

네이버 영어사전을 크롬 탭 대신 **작은 창**으로 띄워 쓰는 PC 프로그램입니다.
제목줄·상단 바 없이 사전 화면만 보이는 위젯 형태로 화면 오른쪽 아래에 작게 뜨고, 다른 창 위에 항상 떠 있으며, 닫으면 트레이(시계 옆)로 숨습니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 창 열기 / 숨기기 | **Ctrl + Shift + Space** (어느 프로그램에서든) 또는 트레이 아이콘 클릭 |
| 단어 바로 찾기 | 엑셀·PDF·메일 등에서 단어를 **Ctrl + C** 로 복사한 뒤 **Ctrl + Shift + F** |
| 창 옮기기 | 마우스를 창 **맨 위 가장자리**에 대면 반투명 손잡이가 나타남 → 가운데를 잡고 끌기 (크기는 창 가장자리를 끌어서 조절) |
| 항상 위 켜기/끄기 | 손잡이의 📌 버튼 |
| 창 숨기기 | Esc 또는 손잡이의 ✕ (종료되지 않고 트레이로 숨음) |
| 스크롤바 | 평소엔 숨겨져 있고 스크롤할 때만 반투명하게 보임 |
| 뒤로 / 앞으로 | Alt + ← / Alt + → |
| 처음 화면 | Alt + Home |
| 종료 | 트레이 아이콘 우클릭 → 종료 |

트레이 아이콘 우클릭 메뉴에서 설정할 수 있는 것:
- 항상 위에 표시 켜기/끄기
- 투명도 (100% ~ 60%)
- 작은 창용 화면 (모바일 레이아웃) 켜기/끄기
- Windows 시작 시 자동 실행
- 설정 파일 열기: 단축키(`hotkeyToggle`, `hotkeyLookup`)나 주소를 바꿀 수 있고, 프로그램을 다시 켜면 적용됩니다.

창 크기와 위치는 저장되어 다음에 같은 자리에 뜹니다.

## 설치

GitHub 저장소의 **Actions → "영어사전 위젯 (Windows 빌드)"** → 가장 최근 실행 →
**Artifacts** 에서 `EnglishDictWidget-windows` 를 내려받아 압축을 풉니다.

- `EnglishDictWidget-setup.exe`: 설치형 (바탕화면 바로가기 생성)
- `EnglishDictWidget-portable.exe`: 설치 없이 바로 실행

코드 서명이 없는 프로그램이라 처음 실행할 때 Windows가
"PC 보호" 창을 띄울 수 있습니다. **추가 정보 → 실행** 을 누르면 됩니다.

## 직접 빌드 (개발자용)

```sh
cd naver-dict-widget
npm install
npm start          # 바로 실행
npm run dist       # dist/ 에 exe 생성 (Windows에서)
```
